# MEMO Service with REST API

## Description

Application is a demo of a simple memos (notes) service

### Used technologies

- Kotlin 2.4.x (JavaLanguageVersion 25)
- Gradle 9.x (wrapper)
- Spring Boot 4
- Spring Web MVC
- Spring Data JPA
- Flyway DB migration tool
- H2 DB
- Logback
- OpenAPI 3 & Swagger UI (springdoc-openapi)
- Docker
- JUnit Jupiter
- MockK
- Springmockk
- Ktlint
- Detekt
- JaCoCo
- Kover
- OWASP

### Functionality

- Application implements CRUD operations for memos and labels
- Memo and label services are `@Transactional` to avoid race condition

## Getting started

### Gradle build

Build with Gradle (wrapper):

```shell
./gradlew build
```

Build continuing on task failures:

```shell
./gradlew --continue build
```

Build deleting the build directory:

```shell
./gradlew clean build
```

### Docker build

To build and tag a Docker image, first build the artifact with Gradle:

```shell
./gradlew build
```

Then build and tag the image with Docker:

```shell
docker build --build-arg APP_VERSION=1.0.0 \
  -t mirogaudi/memo-service:1.0.0 \
  -t mirogaudi/memo-service:latest \
  .
```

Or build and tag a Docker image directly with Gradle via the Docker plugin:

```shell
./gradlew dockerBuildImage
```

### Run

#### Run with Java

```shell
java -jar build/libs/memo-service-1.0.0.jar
```

#### Run with Gradle

Run with Gradle via Spring Boot plugin:

```shell
./gradlew bootRun
```

With `dev` profile:

```shell
./gradlew bootRun --args='--spring.profiles.active=dev'
```

#### Run with Docker

```shell
docker run -it --rm --name memo-service -p 8080:8080 -p 9000:9000 mirogaudi/memo-service:latest
```

#### Run in IDE

Just run in IDE: [MemoServiceApplication.kt](./src/main/kotlin/mirogaudi/memo/MemoServiceApplication.kt)

### View and try Application API

- OpenAPI docs: [http://localhost:8080/ms/v3/api-docs](http://localhost:8080/ms/v3/api-docs)
- Swagger UI: [http://localhost:8080/ms/swagger-ui/index.html](http://localhost:8080/ms/swagger-ui/index.html)
- HTTP client: [request-labels.http](http-requests/request-labels.http), [request-memos.http](http-requests/request-memos.http)

#### Spring Boot Actuator

- Actuator: [http://localhost:9000/actuator](http://localhost:9000/actuator)
- Swagger UI: [http://localhost:8080/ms/swagger-ui/index.html?urls.primaryName=x-actuator](http://localhost:8080/ms/swagger-ui/index.html?urls.primaryName=x-actuator)
- HTTP client: [request-actuator.http](http-requests/request-actuator.http)

## Maintenance

### Update dependencies

Dependencies are to be updated automatically with Renovate/Dependabot or could be updated manually:

#### Update Gradle wrapper:

Replace `9.8.2` with the desired Gradle version.

```shell
./gradlew wrapper --gradle-version 9.8.2
```

#### Check for dependency updates

Check for dependency updates with Ben Manes Versions Gradle plugin

```shell
./gradlew dependencyUpdates --no-parallel
```

### Check Gradle task dependencies

Show Gradle `build` task dependencies order using Gradle dry run:

```shell
./gradlew build --dry-run
```

Show Gradle `build` task dependencies order using Gradle taskinfo plugin:

```shell
./gradlew tiOrder build
```

Task dependencies tree:

```shell
./gradlew tiTree build
```
